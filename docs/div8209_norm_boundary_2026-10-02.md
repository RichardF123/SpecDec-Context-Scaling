# 位置 8209 的最终 RMSNorm 边界：**Norm 输入已经不同**，Norm 形状不改变判定（2026-10-02）

> **本轮只做一件事**：在**同一份 `H(8208)`** 上，把边界从 LM head 再上移一格到**最终 RMSNorm**，
> 区分「**Norm 输入已经不同**」与「**Norm 执行形状改变判断**」。
> **不做**逐层扫描（不扫 28 层）、**不改**算法/公式/精度/门槛、**不做**全模型 FP32、**不做** FP32 投影、
> **不**自由生成、**不**加载 draft、**不**扩 family/算子扫描；GPU 单进程串行；硬失败落盘停止（无自动重试）。
> **B6 未过 ⇒ 本轮的定位不构成任何豁免；正式正确性状态不变（未通过）。**

## 0. 结论摘要（**实测 / 支持性推断 / 未确定** 严格分开）

**实测（本 run 直接测到）**

1. **Norm 输入已经不同**：`xS`（S 路径，(1,1,1536)）vs `xB`（B 路径 (1,4,1536) 第 0 行）——
   **1386 / 1536** 个坐标不同，`max|Δ| = 2.0`（元素 609：63.0 vs 65.0），`mean|Δ| = 0.052181`。
   Norm **输出** `hS` vs `hB`：**1343 / 1536**，`max|Δ| = 1.0`（元素 553：38.0 vs 37.0），
   `mean|Δ| = 0.030425`（与上一轮**逐位一致地复现**）。
   （两者都是 **bf16 原始张量**；只在统计/比较时转 FP32。）
2. **Norm 的执行形状在本例对决策**（行 0）**逐位无影响**：

   | 对照 | 决策向量 | 投影后的判定行 |
   | --- | --- | --- |
   | 固定输入 `xS`、只把 Norm 行数 1→4 | **逐位相同**（`n_diff=0`，`max|Δ|=0`） | **逐位相同**（323→323） |
   | 固定输入 `xB`、只把 Norm 行数 1→4 | **逐位相同**（`n_diff=0`，`max|Δ|=0`） | **逐位相同**（659→659） |

   ⇒ `NC ≡ NA`、`ND ≡ NB`（张量 `torch.equal` 为真），也就是**没有观察到 Norm 形状效应**。
3. **固定 Norm 形状、更换输入 ⇒ 两种形状下都翻转**（见下表 `P_NA↔P_NB`、`P_NC↔P_ND`）：
   `n_diff = 136471 / 151936`、`max|Δ| = 0.25`、`argmax 323 → 659`。
4. **四格控制成立**：`NA` **逐位**复现捕获的 `hS`；`ND` 的第 0 行**逐位**复现捕获的 `hB`；
   每格**重复两次逐位相同**；源张量（`xS/xB4/hS/hB4`）与两份权重全程未变（`n_diff=0`，`data_ptr`/摘要稳定）。
5. **跨 run 交叉核对**：本轮 `P_NA == 上一轮 HS_1`、`P_ND == 上一轮 HB_1`（**同为单行投影，逐位相同**）；
   而 `P_ND` 与上一轮的**四行**投影 `HB_4` 差 **171 个坐标 / `max|Δ|=0.0625`（index 14623）**，
   与上一轮测到的 **LM head 形状效应完全一致**（`P_NA` vs 上一轮 `HS_4`：134 个坐标 / 0.0625 / index 21204）
   ⇒ 该效应**跨 run 可复现**。
6. **三次 run 的测量值逐位相同**（`P_NA/NB/NC/ND` 的 `sha16` 三次完全一致）⇒ 跨进程确定性。

**支持性推断（由上面的数支持，但不是本轮新测到的机制）**

* 按用户给定的归因规则：**固定 Norm 形状换输入会翻转、固定输入换 Norm 形状不翻转 ⇒ 支持「输入差异驱动」**。
  结合上一轮的 LM head 四格（换输入在两种投影形状下都翻转、换投影形状不翻转），
  **差异在到达最终 Norm 之前就已经存在**，并且**穿过 Norm 之后仍然存在**（1343/1536）。
  ⇒ 下一步的边界应转向 **Decoder 堆栈**（本轮**不**扫层）。
* 位置 8209 的两候选在 bf16 上贴边（`margin = 0.125` = 该量级 1 ULP；三格里**精确并列**），
  因此"是否翻转"对 ≤1 ULP 级的差异敏感 —— 这是**贴边**这一事实的延续，不是新的机制。
* 注：Norm 输入差 `max|Δ|=2.0` 与输出差 `max|Δ|=1.0` **不可直接比较大小**
  （Norm 对每一行做逐行重标定；两者是不同量、不同尺度）⇒ 只说"**差异穿过 Norm 后仍然存在**"，
  **不**说"Norm 压缩/放大了差异"。

**未确定（本轮没有测、也不声称）**

* **323 / 659 谁是数学真值**：**没有**做 FP32 对照/FP32 投影 ⇒ **不做** `BF16_NEAR_TIE` 类判定。
* **差异由哪个上游算子产生**：`xS ≠ xB` 只证明"差异在 Norm **之前**已经存在"，
  **不能**据此认定 Decoder 里某个算子、最终 Norm 或某个投影有 bug（需要再上移边界）。
* **不**把"执行路径相关的数值差异"升级为"**必然只是 BF16 舍入**"：
  本轮**没有**区分"bf16 舍入"与"fp32 累加顺序 / kernel 选择 / reduction 切分"这些来源。
* 本结论**只**覆盖"同一份 H、位置 8209、这 4 个候选"；**不**外推到别的位置/长度/历史。
* 本轮**没有**捕获未加诊断的自由生成整行 ⇒ 只说"复现了已保存的局部对照行"，**不**声称与原始自由生成一致。

## 10. 已证实 / 未证实 / 控制失败（**分开列**）

**已证实（本 run 实测）**
1. Norm 输入 `xS ≠ xB`（1386/1536，max 2.0）；Norm 输出 `hS ≠ hB`（1343/1536，max 1.0，复现上一轮）。
2. **Norm 形状改变（行数 1↔4）对决策向量逐位无影响**（`n_diff=0`，两种输入都是）。
3. **固定投影形状、换输入 ⇒ 两种 Norm 形状下都翻转**（136471 坐标、max 0.25、323→659）。
4. 控制：`NA≡hS`、`ND[0]≡hB`（逐位）；每格重复两次逐位相同；源与权重未变；关闭捕获不变；三次 run 测量值逐位相同。
5. 跨 run：`P_NA≡上一轮 HS_1`、`P_ND≡上一轮 HB_1`；与上一轮 `*_4` 的差异**复现**了上一轮的 LM head 形状效应（171/0.0625/14623、134/0.0625/21204）。

**未证实（本轮没有测）**
1. 323/659 谁是数学真值（**未**做 FP32 ⇒ 不做 `BF16_NEAR_TIE` 判定）。
2. 差异由哪个上游算子产生（`xS≠xB` 只说明"差异在 Norm 之前已存在"）。
3. 差异的具体来源分解（bf16 舍入 vs fp32 累加顺序/kernel/reduction 切分）——**不**升级为"必然只是 BF16 舍入"。
4. 8239 与 8209 是否同源；不推广到别的位置/长度/历史。

**控制失败**：**无**。两个真实组合逐位复现捕获输出；位置口径、独立副本、源与权重完整性、关闭捕获等价、
跨 run 交叉核对（单行↔单行）全部成立。缺陷①是**核对目标写错**（已修正并保留原产物），缺陷②③④是**派生字段/口径**问题，
**原始比较字段自始正确**。
