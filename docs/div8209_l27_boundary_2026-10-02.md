7. 源完整性：`aS/aB4/zS/zB4`、两份轮前缓存、其余三行、绑定权重与 Norm 权重**全程未变**（`n_diff=0`、
   `data_ptr`/摘要稳定）；**关闭捕获**时 S/B 判定行逐位不变；两次 GPU run 的四格尾部摘要**逐位相同**。

**支持性推断（由上面的数支持，但不是本轮新测到的机制）**

* 按用户给定的判读规则：**固定 L27 形状换输入会翻转（两种形状下都翻转）**，而
  **固定输入换 L27 形状不翻转** ⇒ 支持**输入来源效应**：L27 在本例中主要在**传递**上游差异，
  它自身的执行路径差异（可测：334/175 个向量坐标、8.4e4–14.1e4 个 logits 坐标、≤0.125）
  **不足以**翻转本例的 323/659。
* 与上一轮（最终 Norm）的**重要区别**：最终 Norm 的行数改变对第 0 行**逐位无影响**（`n_diff=0`），
  而 L27 的行数改变**确实改变了数值**（只是没翻转）⇒ 这两处的"形状效应"**不是同一件事**，
  不能互相套用（也说明"不翻转"≠"无数值影响"）。
* 位置 8209 的两候选在 bf16 上贴边（`margin=0.125` = 该量级 1 ULP；`P_LA/P_LC` 是**精确并列**），
  因此"是否翻转"对 ≤1 ULP 级差异敏感 —— 这是**贴边**事实的延续，不是新机制。

**未确定（本轮没有测、也不声称）**

* **323 / 659 谁是数学真值**：**没有**做 FP32 ⇒ **不做** `BF16_NEAR_TIE` 类判定。
* **差异由哪个上游算子/哪一层首次产生**：`aS≠aB` 只证明"L27 之前已有差异"；
  **不假定差异逐层单调增长**、**不**用简单二分排除更早层（见 §11 的下一步）。
* **不**把数值差异直接判为 bug；**不**用 margin 豁免正确性；**不**声称 B6 通过或修复完成。
* 本结论**只**覆盖"同一份 H、位置 8209、这 4 个候选、这一层"；**不**外推到别的位置/长度/历史。

## 5. 已证实 / 未证实 / 控制失败（**分开列**）

**已证实（本 run 实测）**
1. L27 输入已不同（1357/1536，max 0.5）；L27 输出（= Norm 输入）已不同（1386/1536，max 2.0，复现上一轮）。
2. 捕获链与"对应行/轮前缓存相等"全部**逐位**成立（含 embedding 行、cos/sin 第 0 行、缓存 S≡B≡H[27]）。
3. 固定 L27 形状、换输入 ⇒ **两种形状下尾部都翻转**（135295 / 145577 个坐标，max 0.25，323→659）。
4. 固定输入、换 L27 形状 ⇒ 尾部**不翻转**（argmax 不变），但**数值确实改变**（向量 334/175、logits 141068/83793，max ≤0.125）。
5. 控制：两格逐位复现捕获输出；每格重复两次逐位相同；源/轮前缓存/权重未变；关闭捕获逐位不变；
   跨 run 单行参考四项逐位相同；两次 GPU run 的四格尾部摘要逐位相同。

**未证实（本轮没有测）**
1. 323/659 谁是数学真值（**未** FP32 ⇒ 不做 `BF16_NEAR_TIE` 判定）。
2. 差异**首次**产生在哪一层/哪个算子（`aS≠aB` 只说明"L27 之前已有"；不假定单调、不用二分排除更早层）。
3. 数值差异的来源分解（bf16 舍入 vs fp32 累加顺序/kernel/reduction 切分）——**不**升级为"必然只是 BF16 舍入"。
4. 8239 与 8209 是否同源；不外推到别的位置/长度/历史。

**控制失败**：**无**。缺陷①是"必需控制**过滤器**写错"（已修并保留原产物），不是数据问题；
模块侧发现的三个口径缺陷都在 **CPU 门**里被挡住（**没有**浪费 GPU run，见 §7）。
