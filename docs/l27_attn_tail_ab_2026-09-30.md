## 2. A/B 定义（唯一变量）

```
core（A = G0 四行调用的对齐行；B = G1 单行调用；两者均 (1,1,1536) bf16）
  → o_proj（生产模块）
  → + L27 层输入残差（**BF16 加法**）
  → post_attention_layernorm（生产模块）
  → MLP（生产模块）
  → + 前一步结果（**BF16 加法**）
  → 最终 RMSNorm（生产模块）
  → LM head（`@ embed_tokens.weight.T`）
  → logits / argmax
```
除 `core` 数值外一切相同：残差同一份、权重同一份、dtype 全 bf16、形状全 `(1,1,1536)`、
无新精度开关、**未**用 FP32 求和替代 bf16 加法（由 CPU 自测正面证明两条路径可区分）。

**未新增捕获**：A/B 的 core 与参考 `o_proj` 均来自上一轮 `.pt`；本轮只加载模型模块。**未**跑完整生成。

- MLP 侧：加法后 77/1536，max 与 MLP 输出同级（0.03125）⇒ 保留并进入最终 Norm。

## 5. 最终结果

| 条件 | argmax | 最高分 | margin | 并列集合 | 576 / 715 / 4710 |
| --- | --- | --- | --- | --- | --- |
| **A**（四行 core） | **576** | 17.125 | **0.0** | **3 [576,715,4710]** | 17.125 / 17.125 / 17.125 |
| **B**（单行 core） | **576** | 17.125 | **0.0** | **3 [576,715,4710]** | 17.125 / 17.125 / 17.125 |

- **A/B 是否选择同一 token：是**（576，且三个判决坐标**逐位相同**：`17.125 == 17.125`）。
- top-5（A 与 B 相同）：`576`（`'\n\n'`）、`715`、`4710`、`31906`、`758`（logits 见产物 `.pt` 的 `logits_A` / `logits_B`）。
- **独立参考（不混入 A/B 因果结论）**：
  * A（单行下游）vs **真实四行 block 行**：max\|Δ\|=0.0625、mean 1.87862e-04、8306/151936 不同；
    真实块行同样是 argmax 576、3 方并列 —— **A 不要求等于它**（下游形状已统一为单行）；
  * 参考线（真实 L27 输出行 → 单行 Norm → 单行 LM head）：argmax 576、3 方并列，与 A/B 一致。

## 6. 结论与边界（按任务 §六）

**A/B argmax 相同** ⇒
> **该位置、该固定下游条件下，L27 query 行数导致的 core 差异不足以改变最终选择。**

- **关闭这条局部传播诊断**；
- **不**宣称所有 attention 差异均无关；
- **不**把诊断完成当作正式正确性通过（正式门槛状态**不变**）；
- **不**以某候选的 ULP 归一化整行误差；**未**预设 A 必选 576 / B 必选 4710（两者均由测量得到）。

## 7. 交付问答（任务 §七）

1. **本轮唯一改变了什么？** 只有 L27 对齐行的 **attention core 数值**（A：四行调用 vs B：单行调用）。
   残差（同一份 L27 层输入）、权重、dtype（全 bf16）、形状（全 `(1,1,1536)`）、运算顺序、精度开关**全部相同**。
2. **差异在哪些阶段保留、消失或扩大？**
   保留并在绝对量级上**放大**：core 2/1536（max 4.88e-4，上一轮）→ `o_proj` 23/1536（max 7.8e-3）
   → 残差加法后 1/1536（max 不变）→ MLP 后 max 0.03125 → 最终 logits max **0.0625**（34023 个坐标不同）。
   **但判决三坐标始终逐位相同**，故放大没有触及决定位置。
3. **是否改变最终 token？** **没有**。A = B = **576**，并列结构与 margin 完全一致。
4. **排除了什么，仍不能解释什么？**
   排除：**「L27 query 行数（4 行 vs 1 行）这一调用形状差异」在本位置不足以改变选择**。
   仍不能解释：θ 原始 **AR=715 vs Spec=576** 的成因（本轮**未碰** AR cache）；
   θ 差异**首次产生**在哪一层/算子；θ attention 的 K/V **数值来源**效应（G3 未做）；
   θ 其它位置/其它输入是否同结论（**不能**从本例外推）。
5. **这条诊断是否可以收束？** **可以收束**（局部传播链已走到终点且未改变选择）。
   若还要继续，**唯一**值得做的是 K/V **来源**替换（G3）——但那需要先解决「AR 历史与同历史串行 cache
   不可混用」的设计问题，且要另行批准。
